
# Minecraft JS

## Description
A simple Minecraft game built with HTML, CSS and JavaScript.
The player can choose a tool, remove blocks and place collected blocks back into the world.

## What I found hard
The hardest part was connecting the tools to the correct blocks and making the inventory work correctly.

## Known bugs
No known bugs.

## Assignment review
This assignment helped me understand how JavaScript can interact with HTML and CSS.
I practiced using events, functions and arrays to create a simple interactive game.
